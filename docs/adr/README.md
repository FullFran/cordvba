# Architecture Decision Records — cordvba root

Root-level ADRs, for decisions that cross component boundaries. Follows the
same convention as `apps/eye/docs/adr/`: append-only, numbered, using
[`apps/eye/docs/adr/template.md`](../../apps/eye/docs/adr/template.md).

eye keeps its own ADR series under `apps/eye/docs/adr/` for decisions local
to eye. A decision goes here only when it affects more than one component
or the monorepo layout itself.
